# Roadmap

- Add an accessible, CSRF-protected administration surface for explicit
  organization, authorization, and calendar-context configuration.
- Add the app-local permission and privacy providers if future app-owned user
  endpoints or persisted personal values make them applicable.
- Prove the enabled-app DI, background-job, provider-failure, deactivation,
  removal, and reinstall matrix in the authorized Nextcloud runtime.
- Decide public App Store suitability and maintainer governance before any
  publication.
